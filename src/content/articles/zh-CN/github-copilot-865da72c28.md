该研究基于 GitHub 的专有 Copilot 使用数据，考察生成式 AI 对开源软件协作的影响。作为预印本，研究尚未经过同行评审。

研究发现，Copilot 的使用使项目级代码贡献增加 5.9%，开发者编码参与度提高 3.4%，个人代码贡献增加 2.1%。同时，协调时间增加 8%，代码讨论增多。总体效果仍为正面，项目级代码贡献的及时合并净增加。边缘开发者比核心开发者的项目贡献增幅更小，而协调时间增幅更大。

由于研究依赖 GitHub 的专有使用数据，且摘要未提供详细方法和统计模型，结果可能存在偏差。此外，作为预印本，研究未经同行评审，结论应谨慎解读。
