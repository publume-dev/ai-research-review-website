Radiology report generation is an important task in medical AI, yet it lacks standardized benchmarks. ReXrank aims to address this by providing a public leaderboard and challenge using the largest test dataset, ReXGradient, with 10,000 studies, along with three public datasets: MIMIC-CXR, IU-Xray, and CheXpert Plus.

The ReXrank framework employs 8 evaluation metrics and separately assesses models capable of generating only the findings section and those providing both findings and impressions sections. This distinction allows for a more nuanced evaluation of model capabilities.

The abstract does not provide any quantitative results or comparisons of model performances, so the actual performance and rankings on this benchmark remain to be seen.
