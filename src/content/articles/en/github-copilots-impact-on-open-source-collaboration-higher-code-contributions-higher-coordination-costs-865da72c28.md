The study uses GitHub's proprietary Copilot usage data to examine the effect of generative AI on open-source software collaboration. As a preprint, it has not undergone peer review.

The research finds that Copilot usage increases project-level code contributions by 5.9%, developer coding participation by 3.4%, and individual code contributions by 2.1%. It is also associated with an 8% increase in coordination time and more code discussions. The overall effect remains positive, with a net increase in timely merges of code contributions at the project level. Peripheral developers see smaller increases in project contributions and larger increases in coordination time than core developers.

Because the study relies on GitHub's proprietary usage data and the abstract does not detail the methodology or statistical models, results may be subject to bias. Moreover, as a preprint, the findings have not been peer-reviewed and should be interpreted with caution.
